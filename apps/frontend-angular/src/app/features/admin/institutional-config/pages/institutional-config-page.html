Cómo impactan estos cambios

  • Los cambios impactan únicamente en los nuevos documentos generados después de guardar.
  • Si se modifican firmas o autoridades, los certificados ya compartidos manualmente no cambian hasta que se regenere el PDF.
  • Estos datos no se editan en la pantalla de emisión individual.

04

Contacto institucional

Dato de contacto que figura como referencia. No es un sistema de envío.

@

Se muestra como referencia. El sistema no envía correos automáticamente.

La entrega de certificados es manual

  • El sistema no cuenta con envío de emails (sin SMTP) ni opción de «reenviar» desde esta pantalla.
  • La entrega se hace copiando el link de validación o descargando el PDF.
  • Ante entregas manuales repetidas del mismo certificado, el código QR permanece igual.
