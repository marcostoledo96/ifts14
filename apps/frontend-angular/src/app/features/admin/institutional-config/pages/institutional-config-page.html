Configuración institucional

Estos datos se aplican a los certificados emitidos por el sistema. Se configuran una sola vez acá y no se editan en la pantalla de emisión individual.

Cómo impactan estos cambios

  • Los cambios impactan únicamente en los nuevos documentos generados después de guardar.
  • Si se modifican firmas o autoridades, los certificados ya compartidos manualmente no cambian hasta que se regenere el PDF.
  • Estos datos no se editan en la pantalla de emisión individual.

01

Identidad institucional

Nombre que encabeza cada certificado y el PDF.

Aparece como encabezado principal del certificado.

Logos y sellos

La carga de logos institucionales no está disponible: no hay API de archivos en esta versión. Los sellos visuales del PDF siguen el diseño fijo del sistema.

02

Certificados

Texto base que estructura el cuerpo de cada documento emitido.

Cuerpo del certificado. Los datos del alumno y del curso se completan automáticamente en cada emisión.

Título, numeración, QR y sello

El título del documento, el formato de número, el link base del QR y el toggle de sello institucional no se editan acá: no forman parte del contrato de configuración persistido.

04

Contacto institucional

Referencia de contacto. No es un sistema de envío.

La entrega de certificados es manual

  • El sistema no cuenta con envío de emails (sin SMTP) ni opción de «reenviar» desde esta pantalla.
  • La entrega se hace copiando el link de validación o descargando el PDF.
  • Ante entregas manuales repetidas del mismo certificado, el código QR permanece igual.
05

Validación pública

Textos que ve cualquier persona al verificar un certificado por QR.

Mensajes fijos en la aplicación

Los textos de la página pública de validación (válido, revocado, no encontrado) y el enlace al sitio del instituto no se editan desde esta pantalla. Ante cambios, contactar al equipo técnico.
